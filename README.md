## How to Use This Plan

1. Dedicate **2 hours daily**: 1 hour for Python, 1 hour for JavaScript.
2. Push your code to **GitHub every day** to maintain a streak.
3. Use a **README.md** in your root folder to describe your journey.
4. On weekends, revise and complete the **mini project**.
